# PythonProject_Django

### Создание Онлайн Магазина при помощи фреймворка Django

Проект представляет собой начальный шаблон интернет-магазина, работающий на локальном хосте по адресу `127.0.0.1:8000`. Магазин имеет две страницы: **Каталог** и **Контакты**. Страницы представляют собой HTML файлы, с подключенными стилями Bootstrap. Стили подключены локально.

## Структура проекта

- **Главная**
- **Контакты**

Все конфиденциальные переменные, такие как `SECRET_KEY`, `DEBUG`, и другие, вынесены в файл `.env`. Файл `.env` необходимо создать вручную в корне проекта по образцу, представленному в файле `.env.example`.

## Требования

Проект использует Python 3.x и Poetry для управления зависимостями.

- Python >= 3.10.12
- Poetry >= 2.1.2
